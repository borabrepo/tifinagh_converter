# ⵜⵉⴼⵉⵏⴰⵖ — محوّل تيفيناغ

محوّل كتابة يحوّل ما تكتبه بالحروف العربية أو بالحروف اللاتينية (بنطق فرنسي) إلى تيفيناغ وفق معيار المعهد الملكي للثقافة الأمازيغية (IRCAM)، ويحوّل أيضاً في الاتجاه المعاكس من تيفيناغ إلى العربية أو اللاتينية.

التطبيق صفحة واحدة تعمل كاملة داخل المتصفّح: لا خادم، لا حساب، ولا يغادر النص جهازك.

**التطبيق مباشرة:** https://borabrepo.github.io/tifinagh_converter/

---

## ما الذي يفعله

- **واجهة بثلاث لغات**: العربية والفرنسية والإنجليزية، تُختار تلقائياً حسب لغة المتصفّح وتُبدَّل بضغطة، مع قلب اتجاه الصفحة بين RTL وLTR.
- **تحويل فوري** أثناء الكتابة، مع كشف تلقائي للغة المدخل (عربية / لاتينية) أو اختيارها يدوياً.
- **تحويل عكسي** من تيفيناغ إلى:
  - لاتيني بأسلوب فرنسي (ⵓ ← ou، ⵛ ← ch، ⵅ ← kh، ⵖ ← gh)،
  - لاتيني بالأبجدية البربرية اللاتينية العلمية (ⵛ ← c، ⵅ ← x، ⵖ ← ɣ، ⵄ ← ɛ، مع ḍ ṣ ṭ ẓ ṛ ḥ)،
  - أو حروف عربية، بخيار الشدّة وهمزة أول الكلمة.
- **لوحة مفاتيح تيفيناغ** على الشاشة (41 رمزاً مع علامة التفخيم ⵯ) لأن الهواتف لا توفّرها.
- **مدخل مختلط**: يمكن خلط الحروف العربية باللاتينية والمفخّمات في الكلمة الواحدة؛ `أضار` و`aḍar` كلاهما ⴰⴹⴰⵔ.
- **عرض المطابقة حرفاً بحرف** لمراجعة كل رمز ومعرفة مصدره، مع تمييز ما أُدرج تلقائياً.
- **شريط مواضع** يتيح وضع مؤشّر الكتابة بين أي حرفين بالضغط، وأزرار تشكيل (ـّ ـَ ـُ ـِ ـْ) وحروف لاتينية مفخّمة (ḍ ṣ ṭ ẓ ṛ ḥ ɛ ɣ) يصعب كتابتها من لوحة مفاتيح الهاتف.
- **مظهر فاتح وداكن** أو اتّباع إعداد الجهاز.
- نسخ النتيجة بضغطة، وجدول مطابقة كامل مع أرقام يونيكود.
- يعمل دون إنترنت بعد أول فتح، وقابل للتثبيت على الشاشة الرئيسية.

## القواعد المطبَّقة

### خط المعالجة

1. **تنظيف وتوحيد**: توحيد يونيكود (NFC)، حذف التطويل، خفض حالة الحروف مع الحفاظ على نقاط التفخيم، وقبول كتابة المفخّم بنقطة لاحقة (`d.` `s.` `t.` `z.` `r.` `h.`).
2. **مطابقة جشعة بالأطول أولاً**: `ghw` قبل `gh` قبل `g`، فلا تتفكّك `ch` و`kh` و`ou` إلى حروف مفردة.
3. **قواعد صوتية**: الشدّة، التمييز بين u/w و i/y، وإدراج ⴻ.
4. **إخراج** في نطاق تيفيناغ U+2D30–U+2D7F.

### التضعيف

يُكتب بتكرار الحرف نفسه، ولا علامة خاصة له في لائحة IRCAM: `ⵜⴰⵎⵎⵏⵜ`، `ⴱⴷⴷⵍ`، `ⵉⵎⵉ` مقابل `ⵉⵎⵎⵉ`. في العربية تُوسَّع الشدة U+0651 إلى حرفين، وفي اللاتينية يبقى الحرف المكرّر مكرّراً.

ما يخصّ ⴳ برمز خاص شيئان مختلفان عن التضعيف: علامة تامّاطارت ⵯ (U+2D6F) للتفخيم الشفوي `ⴳⵯ` و`ⴽⵯ` (وفي اللائحة الموسّعة `ⵇⵯ` `ⵅⵯ` `ⵖⵯ`)، وحرف `ⴴ` الموسَّع لصوت ʝ.

### التمييز بين الصامت والصائت

| الحالة | النتيجة | مثال |
|---|---|---|
| `w` اللاتينية | ⵡ دائماً | — |
| `ou` | ⵓ، وأمام حرف علة ⵡ | Ouarzazate ← ⵡⴰⵔⵣⴰⵣⴰⵜ |
| `y` | ⵢ بجوار حرف علة، وإلا ⵉ | — |
| «و» أول الكلمة أو بعد صائت | ⵡ | والو ← ⵡⴰⵍⵓ |
| «و» بعد صامت | ⵓ | أزول ← ⴰⵣⵓⵍ |
| «ي» أول الكلمة | ⵢ | يالاه ← ⵢⴰⵍⴰⵀ |
| «إ» | ⵉ | إمازيغن ← ⵉⵎⴰⵣⵉⵖⵏ |
| ألف حاملة + و + صامت | ⵓ | أوسان ← ⵓⵙⴰⵏ |

### إدراج ⴻ

عند التقاء ثلاثة صوامت يُدرج ⴻ بين الثاني والثالث (`drs ← ⴷⵔⴻⵙ`)، دون كسر الحرف المضعَّف. الخيار قابل للإيقاف لمن يريد الإملاء المجرّد الذي لا يكتب الشوا.

### الحركات والتاء المربوطة

الفتحة ← ⴰ، الضمة ← ⵓ، الكسرة ← ⵉ، مع دمج الحركة وحرف المدّ إن تكرّرا. السكون يُهمَل وتتكفّل به قاعدة ⴻ. التنوين يُفكّ. التاء المربوطة ← ⵜ. والألف المقصورة ← ⴰ.

## خيارات المحرك

**اتجاه «إلى تيفيناغ»**

| الخيار | الأثر |
|---|---|
| إدراج ⴻ | فكّ توالي السواكن |
| قراءة g دائماً ⴳ | عند إيقافه تُطبَّق القاعدة الفرنسية: g قبل e/i ← ⵊ |
| تجاهل e الصامتة | حذف e في آخر الكلمة |
| أرقام الدردشة | 3 ← ⵄ، 7 ← ⵃ، 9 ← ⵇ، 5 ← ⵅ |
| الحروف الموسّعة | ⴲ ⵝ ⴸ ⴺ ⴴ والمركّبات ⴷⵊ ⵜⵙ ⴷⵣ |
| حذف «الـ» التعريف | من المدخل العربي |

**اتجاه «من تيفيناغ» نحو العربية**

| الخيار | الأثر |
|---|---|
| استعمال الشدة | ⵡⴰⵏⵏⴰ ← وانّا بدل واننا |
| همزة أول الكلمة | ⵓⵙⵙⴰⵏ ← أوسّان بدل وسّان |

## التثبيت على الهاتف

افتح رابط التطبيق في Safari (آيفون) أو Chrome (أندرويد)، ثم زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. يفتح بعدها كتطبيق مستقل بملء الشاشة، ويعمل دون اتصال.

## التشغيل محلياً

```bash
git clone https://github.com/borabrepo/tifinagh_converter.git
cd tifinagh_converter
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. ملف `index.html` وحده يعمل بفتحه مباشرة، لكن التخزين للعمل دون إنترنت يحتاج خادماً (HTTPS في الإنتاج).

## البنية

```
index.html              التطبيق كاملاً: الواجهة، الترجمات، ومحركات التحويل

sw.js                   عامل الخدمة للعمل دون إنترنت
```

بلا أطر عمل ولا اعتماديات؛ جافاسكربت خالصة. الخط: Noto Sans Tifinagh مع بدائل من الجهاز.

## حدود معروفة

- المدخل العربي غير المشكول يبقى ملتبساً في مواضع (و/ي خاصة)، والقواعد اجتهاد على الأشيع.
- التحويل العكسي ليس نسخة طبق الأصل: ⴻ لا مقابل لها بالعربية فتُهمَل، والمفخّمات تضيع في الأسلوب اللاتيني الفرنسي — الأسلوب العلمي وحده يحفظها للرجوع.
- التفخيم الشفوي `ⴳⵯ` يحتاج كتابته `gw` صراحة؛ لا يُستنتج من العربية.
- المعيار موحَّد بين تاريفيت وتمازيغت وتاشلحيت، فبعض النطق المحلي لن ينعكس حرفياً.

# Tifinagh Converter

A browser-based transliteration engine that converts Arabic script or French-style Latin input into Tifinagh following IRCAM's standard orthography for Standard Moroccan Amazigh — and back again.

**Live app:** https://borabrepo.github.io/tifinagh_converter/

Single HTML file, no dependencies, no server — text never leaves the device. Installable as a home-screen app and works offline.

**Features:** trilingual interface (Arabic / French / English) with automatic RTL/LTR switching; live conversion with automatic script detection; reverse conversion from Tifinagh to Latin (French style or the scientific Berber Latin alphabet) or to Arabic, with an on-screen 41-key Tifinagh keyboard; mixed input, so `أضار` and `aḍar` both give ⴰⴹⴰⵔ; per-character mapping trace; a caret ribbon for placing the cursor between any two letters plus diacritic keys; light/dark/system theming; full mapping tables with Unicode code points.

**Implemented rules:** four-stage pipeline (normalise → longest-match-first digraphs → phonological rules → Unicode output); gemination by letter doubling (IRCAM has no dedicated sign for it, ⴳ included); shadda expansion from Arabic; u/w and i/y disambiguation by position; optional ⴻ insertion to break three-consonant clusters; optional IRCAM extended set (ⴲ ⵝ ⴸ ⴺ ⴴ, digraphs ⴷⵊ ⵜⵙ ⴷⵣ) and labiovelars ⴳⵯ ⴽⵯ ⵇⵯ ⵅⵯ ⵖⵯ.

**Developed and designed by borabrepo.** Corrections to the linguistic rules are welcome via Issues.
